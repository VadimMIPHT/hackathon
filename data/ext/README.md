# Умный поиск в Почте · расширенный датасет

Архив на основе [публичного датасета VK](https://cloud.mail.ru/public/8S62/oQDJV17v6). Сохранены исходные имена файлов и поля JSONL.

| Файл | Данные |
| --- | --- |
| `documents.jsonl` | 16 376 писем. Поля `doc_id`, `synthetic_user`, `doc`, `doc_dt`. Файл скопирован из архива VK побайтно. |
| `queries_dev.jsonl` | 139 запросов. Поля `query_id`, `synthetic_user`, `query`, `query_date`. |
| `qrels_dev.jsonl` | 3 786 оценок. Поля `query_id`, `doc_id`, `relevance`. |
| `manifest.json` | Число записей и контрольные суммы SHA-256. |

JSONL в UTF-8. Один объект на строку. Даты имеют формат `YYYY-MM-DD`. Поиск выполняется в ящике `synthetic_user`. Относительные даты отсчитываются от `query_date`. Письма, полученные после этой даты, недоступны. `doc_dt: null` означает неизвестную дату получения.

## Состав разметки

- 565 исходных положительных пар VK.
- 2 078 пар ручной разметки, включая 16 положительных и 2 062 отрицательных. У 13 положительных и 8 отрицательных меток средняя уверенность. Уровни уверенности и индивидуальные пояснения доступны в отдельных исходных файлах ручной проверки.
- 1 143 положительные пары для 40 дополнительных запросов с ID `SYN-10PLUS-001`–`SYN-10PLUS-040`. Из них 32 запроса переформулируют исходные, 8 охватывают несколько дней. Положительные письма унаследованы из VK. У каждого нового запроса 10–133 размеченных письма.

`relevance: 1` означает релевантное письмо. `relevance: 0` означает явно размеченную отрицательную пару. При вычислении метрик, как и в оригинале, пара без записи получает 0. Для подсчёта числа релевантных писем учитываются только строки с `relevance: 1`. Новые формулировки и запросы за несколько дней используют письма из исходных запросов VK, поэтому их оценки зависят от той же исходной разметки.
