# Письмо

Интерактивная почта для кейса VK Tech Hackathon «Семантический поиск по личной почте».

В приватной версии Sites два вымышленных ящика. Поиск по словам сравнивает токены, а поиск по смыслу дополнительно использует словарь выражений и тематическую разметку вымышленных писем. В обоих режимах доступны фильтры по отправителю и периоду и поиск по номеру заказа.

«Спросить» разбирает запрос на текст и поддерживаемые поля поиска, затем показывает выдержки и источники. Для вопросов о сроке и сумме ответ появляется, если найдено подходящее свидетельство в тексте или карточке письма. Обработка выполняется в интерфейсе без внешнего LLM API. По ссылке на источник письмо открывается рядом с ответом.

Напоминания в Sites хранятся в D1 по идентификатору пользователя и почтовому ящику. Интерфейс сравнивает сохранённый срок с текущим временем и отмечает сработавшие записи в папке «Напоминания». Метки избранного, прочитанного и архива хранятся в браузере.

В Refero взяли [поиск и фильтры Missive](https://refero.design/flows/6274), [ответ с источниками Parallel](https://refero.design/flows/9073) и [выбор времени Missive](https://refero.design/flows/6281).

## Локальное демо

Из этой папки выполните команды в Node.js 22.13+ и откройте http://127.0.0.1:8941/. Локальный Worker использует SQLite в `.preview/`.

```bash
node scripts/build.mjs
node scripts/preview.mjs
```

## Подключение архива хакатона

Запустите сервер из корня репозитория `vk-mail-search` и откройте http://127.0.0.1:8940/. По умолчанию сервер подхватывает интерфейс из `sites/pismo/dist` и архив из `data/mipt_mail_search_participants.zip`. Если файлы лежат отдельно, укажите `--dist` и `--archive`.

Для проверки на ноутбуке достаточно Python 3.10+ и BM25.

```bash
python3 -m mail_search.web --archive /path/to/mipt_mail_search_participants.zip --lexical-only
```

Для E5 и BGE на GPU используйте существующее окружение проекта. Укажите один свободный GPU и пути к базовым моделям и дообученным весам.

```bash
CUDA_VISIBLE_DEVICES=<gpu-id> python -m mail_search.web \
  --archive /path/to/mipt_mail_search_participants.zip \
  --e5-model models/e5-small-614241f \
  --bge-model models/bge-reranker-v2-m3-953dc6f \
  --bge-weights runs/compare-r1/bge-returns/best-finetuned.safetensors
```

В режиме «По смыслу» E5 строит индекс для выбранного ящика при первом запросе. BGE пересортировывает до 50 кандидатов. Следующие запросы используют готовые embeddings ящика из памяти процесса. Дату запроса можно изменить в шапке. Она задаёт срез почтового ящика и точку отсчёта для «вчера». Сервер слушает только loopback. Если он запущен на сервере, используйте SSH port forwarding.

Сервер корпуса хранит напоминания в отдельном файле SQLite. Путь можно переопределить флагом `--reminders-db`. В пакет Sites входят интерфейс, Worker и схема базы. Данные архива и веса моделей остаются в окружении корпуса.
