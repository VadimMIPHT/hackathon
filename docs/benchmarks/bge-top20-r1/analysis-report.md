# Повторное ранжирование писем BGE

На val из 21 запроса и двух размеченных ящиков лучший nDCG@10 показал **BGE, эпоха 2**. Для готового BGE изменение относительно порядка E5 составило +0.0023, для лучшей обученной эпохи — +0.0189. Дообучение изменило nDCG@10 относительно готового BGE на +0.0166.

| Вариант | nDCG@10 | Recall@10 | Recall@50 | MRR@10¹ | p50 этапа, мс | p99 этапа, мс |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| E5 | 0,8819 | 0,7938 | 0,9814 | 1,0000 | 14,7 | 25,1 |
| Готовый BGE | 0,8842 | 0,7470 | 0,9814 | 0,8000 | 77,6 | 159,5 |
| BGE, эпоха 1 | 0,8955 | 0,7566 | 0,9814 | 0,8000 | 55,6 | 81,7 |
| BGE, эпоха 2 | 0,9008 | 0,7829 | 0,9814 | 0,8000 | 58,7 | 70,2 |

¹ MRR@10 рассчитан для пяти запросов с одним релевантным письмом. Для строки E5 задержка взята из зафиксированного прогона retrieval. Для BGE измерен исключительно повторный скоринг top-20 вместе с токенизацией и сортировкой. Это последовательные офлайн-замеры, p99 равен максимуму на 21 запросе. На серверный SLA потребуется нагрузочный тест.

## Что сравнивалось

Для каждого запроса готовый и обученный BGE перемещают только первые 20 писем из выдачи E5 с фильтром по дню. Хвост выдачи сохранён. В train все 1 324 пары допустимого ящика и дня, 325 положительных и 999 с нулевой меткой по правилам архива. Обучались последние два слоя и классификационная голова, BCE с одинаковым суммарным весом каждого из 55 запросов. Лучшая обученная эпоха выбрана по nDCG@10 на val, независимая проверка выбранного варианта зарезервирована в test.

Обученный чекпоинт повторно загрузили отдельно. Он восстановил все выдачи лучшей эпохи.
