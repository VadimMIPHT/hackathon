# Первый замер поиска писем VK

На val из 21 запроса и двух размеченных ящиков лучший средний nDCG@10 показал multilingual E5 с фильтром по дате из текста. Прирост составил 0.3050 относительно BM25 и 0.1328 относительно RRF при одном и том же фильтре. На train E5 также лидирует по nDCG@10 в обоих режимах. Эти прогоны проводились без дообучения. Test из 23 запросов зарезервирован.

Фильтр по дате сократил медианное число кандидатов с 980 до 82 на val и с 401 до 12 на train. Сохранились все 157 val и 325 train qrels. При построении выдачи дата извлекается только из текста запроса, а «вчера» вычисляется относительно `query_date`. BM25 пересчитывает IDF и среднюю длину на доступных письмах.

E5 с датой даёт Recall@50=0.9814 на val. Для улучшения верхних позиций здесь остаётся больше пространства, чем для расширения списка кандидатов. Этот вывод ограничен публичной разметкой, где все 76 проверенных запросов содержат явную или относительную дату. Когда такого ограничения нет, E5 в режиме `as_of` даёт Recall@50=0.6400 на val.
