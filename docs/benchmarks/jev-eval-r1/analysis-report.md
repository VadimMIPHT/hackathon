# Поиск по письмам на полной разметке Jev

На 139 запросах E5 → дообученный BGE набрал **0,9657 nDCG@10** и **0,7627 Recall@10**. На 30 запросах из двух test-ящиков оценки BGE и дообученного Qwen практически совпали. После замены разметки на 40 дополнительных запросах BGE сохранил первое место.

## Изменения в разметке

Проверены все 2 276 264 пары из `qrels_full.jsonl` (139 запросов × 16 376 писем). У каждой пары есть единственная явная метка. Из них 1 891 имеют `1` и 2 274 373 имеют `0`. Положительные пары файла `qrels_dev.jsonl` точно совпадают с единицами полного файла. Письма побайтно совпадают с архивом VK. У запросов совпадают текст, ящик и дата. Идентификаторы дополнительных запросов изменились с `SYN-10PLUS-*` на `N-*`.

| Запросы и версия для сравнения | Раньше `1` | Jev `1` | Раньше без метки, Jev `1` | Раньше явный `0`, Jev `1` | Раньше `1`, Jev `0` |
| --- | ---: | ---: | ---: | ---: | ---: |
| 99 исходных, публичные qrels VK | 565 | 721 | 157 | 0 | 1 |

Все оценки в новой версии выставлены моделью `typesafe/jev-1.14` согласно README архива. Совпадение с прежней разметкой измеряет согласованность версий. Чтобы выяснить, какая метка верна, нужно смотреть запрос и письмо.

## Метрики на метках Jev

Далее используется расширенный парсер дат. Поиск ограничен ящиком и датой запроса. При распознавании диапазона в тексте берутся письма внутри этого диапазона. Все реранкеры сортируют один и тот же top-50 E5 для каждого запроса. Для 40 дополнительных запросов переиспользованы прежние выдачи. Для 99 исходных запросов выдачи получены на H200. Замеры с текущим фильтром дат (`frozen`) есть в [метриках](metrics.json).

| Модель | nDCG@10, 139 | nDCG@10, исходные 99 | nDCG@10, дополнительные 40 | nDCG@10, test 30 | Recall@10, 139 | MRR@10, singleton¹ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| E5 | 0,8624 | 0,8804 | 0,8179 | 0,9929 | 0,6865 | 0,9737 |
| E5 → BGE дообученный | 0,9657 | 0,9651 | 0,9673 | 0,9954 | 0,7627 | 1,0000 |
| E5 → Qwen базовый | 0,9278 | 0,9434 | 0,8892 | 0,9915 | 0,7302 | 0,9868 |
| E5 → Qwen дообученный | 0,9112 | 0,9494 | 0,8169 | 0,9949 | 0,7187 | 1,0000 |

¹ MRR по 38 запросам с ровно одним релевантным письмом. Recall@50 одинаков для всех моделей, поскольку список кандидатов общий. Средний Recall@50 составляет 0,9531 по всем запросам, 0,9764 по 99 исходным, 0,8954 по дополнительным 40, 0,9993 по test. Общие 139 включают 71 запрос из train-ящиков, 38 из val и 30 из test. Из 40 дополнительных запросов 32 перефразируют исходные и восемь объединяют несколько дней. На семи дополнительных запросах из одного test-ящика nDCG@10 у BGE и дообученного Qwen равен 1,0000. Эти результаты показывают качество на данном корпусе и метках Jev.

Из 28 новых единиц ни одна не появилась в top-10 трёх реранкеров. E5 держал три такие пары в top-10. Добавленные единицы увеличили число релевантных писем в знаменателе Recall@10. В режиме `date-aware` изменение nDCG@10 реранкеров на 40 запросах целиком приходится на `N-008`. Дообучение Qwen подняло nDCG@10 на исходных 99 на 0,0060, а на дополнительных 40 снизило на 0,0723 при новых метках.
