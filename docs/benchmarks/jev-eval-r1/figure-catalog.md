# Графики оценки Jev

## nDCG@10 по группам запросов

Среднее по запросам для каждой модели при расширенном фильтре дат. Исходные и дополнительные запросы образуют две непересекающиеся группы. Test берёт запросы из обеих групп. График показывает, что BGE лидирует в каждой группе, а дообученный Qwen заметнее теряет балл на дополнительных запросах. На test все модели близки к потолку nDCG@10. Точки соответствуют фиксированным чекпойнтам, разброс между обучениями не измерен. [График](figures/ndcg-by-cohort.pdf) · [Источник](metrics.json).

## Изменение nDCG@10 при смене разметки

Столбцы показывают разность nDCG@10 по Jev и прежним меткам на той же выдаче и при расширенном фильтре дат. Для 99 исходных запросов старый источник — qrels VK, для 40 дополнительных — предыдущий расширенный архив. На 99 исходных разметка снизила nDCG@10 у всех моделей, порядок BGE и Qwen сохранился. На 40 дополнительных небольшое падение у реранкеров связано с одной изменённой меткой на `N-008`. [График](figures/qrel-effect.pdf) · [Источник](metrics.json).
