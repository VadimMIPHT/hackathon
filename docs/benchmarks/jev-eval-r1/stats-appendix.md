# Статистическое приложение

Основное сравнение использует nDCG@10 с бинарными оценками Jev, макроусреднённый по запросам. Дополнительные метрики Recall@10 и Recall@50 также усредняются по запросам. MRR@10 считается на запросах с одной единицей. Один детерминированный порядок документов на фиксированный запрос и модель. Наблюдения по моделям парные. Для одинаковых запросов зафиксированы письма, дата, размер списка и tie-break по `doc_id`.

Фиксированные корпус и чекпойнты, 7 ящиков в общей выборке, 5 в дополнительных запросах, 2 в test. Перефразы и запросы по пересекающимся периодам внутри ящика коррелируют. Диапазоны показывают чувствительность к составу ящиков. Независимых запусков обучения и независимой выборки ящиков для доверительных интервалов и тестов значимости нет. Результаты описательные, множественные гипотезы не тестировались. [Полные метрики, число наблюдений и парные контрасты по всем разрезам](metrics.json).
