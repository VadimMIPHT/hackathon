# Почему основной поиск использует BM25 с локальным IDF

Сравнили лексический и векторный поиск, гибриды и реранкеры на одинаковых запросах. В итоговом сервисе BM25 считает частоту слов внутри отфильтрованных писем. Для ранжирования достаточно CPU.

| Вариант | nDCG@10, Jev 139 | nDCG@10, новые 40 по Jev | nDCG@10, публичные VK 99 | nDCG@10, локальный VK test 23 |
| --- | ---: | ---: | ---: | ---: |
| BM25, глобальный IDF | 0,9748 | 0,9485 | 0,9632 | 1,0000 |
| **BM25, локальный IDF** | **0,9800** | **0,9722** | 0,9562 | **1,0000** |
| E5 → дообученный BGE | 0,9657 | 0,9673 | 0,9802¹ | 0,9940 |

¹ В 99 исходных запросов входят запросы, использованные для обучения BGE. В локальный test они не входят. На 30 запросах в test-ящиках с метками Jev оба BM25 получили 1,0000. Дополнительный набор использует те же письма, включает 32 перефраза и 8 запросов с периодами. В исследовании локального IDF основной прирост на новых запросах дали два перефраза из одного ящика. Закрытый тест организаторов остаётся отдельной проверкой. [Разбор BM25 команды](team-smartmail/README.md) · [E5 и BGE на Jev](jev-eval-r1/analysis-report.md) · [Локальный тест E5 и BGE](final-test/analysis-report.md)

Выдача веб-API совпала с сохранённой выдачей локального BM25 **на 139 из 139 запросов**, включая порядок документов. В двух последовательных проходах по localhost на уже построенном индексе **p99 HTTP составил 12,04 и 9,05 мс**. Замер включает получение и разбор ответа на клиенте. Нагрузка жюри и стартовое построение индекса в этот замер не входят.

## Повторить сравнение

Нужны Python 3.11+ для скрипта, оригинальный ZIP и распакованная версия Jev с файлами `documents.jsonl`, `queries_dev.jsonl` и `qrels_dev.jsonl`. Архив Jev имеет SHA-256 `13479c78fbbb8d40df402c5d8ea9df21253526e28d52a931679fdb6900ba169f`. Воспроизводимая конфигурация использует `k1=1.5`, `b=0.75`, `subject_boost=1`, top‑50 и разбиение по ящикам с seed 42. Сам BM25 детерминирован. Исходный движок использован с ревизии `afd7fd2db71edf87c9b41d2b490fc72efc3f882b`, в веб-сервис он добавлен коммитом `e31acdd3d819dcda9d4f5d7e48dc5872bd7fddcb`. [Скрипт оценки](team-smartmail/benchmark.py) · [Разбиение](mailbox-split.json)

Сначала запустите сервис командой из [README](../../README.md#запуск), затем выполните:

```bash
PYTHONPATH=. python3 docs/benchmarks/team-smartmail/benchmark.py \
  --jev /path/to/unpacked-vk-jev-dataset \
  --public /path/to/mipt_mail_search_participants.zip \
  --mailbox-split docs/benchmarks/mailbox-split.json \
  --team-commit afd7fd2db71edf87c9b41d2b490fc72efc3f882b \
  --metrics-commit "$(git rev-parse HEAD)" \
  --idf-mode local --search-url http://127.0.0.1:8940/api/search \
  --output /tmp/bm25-local-idf.json
```

Чтобы получить контроль с глобальным IDF, повторите с `--idf-mode global`, уберите `--search-url` и укажите другой выходной файл. JSON сохраняет полный порядок писем по запросам, метрики, окружение и хеши входов.
