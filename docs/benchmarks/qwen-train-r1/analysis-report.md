# Дообучение Qwen на выборке BGE

Обе модели использовали те же 1 355 пар из 63 запросов train, включая 31 проверенную пару по возвратам. В каждой выборке 333 положительные пары. Совпадение набора проверено по исходному архиву, манифесту, SHA-256 дополнительной разметки и числу меток. Зафиксированы seed 42, две эпохи, batch size 16, AdamW 2e-5, BCE с одинаковым суммарным весом каждого запроса. У Qwen обучались два последних трансформерных блока, у BGE — два последних блока и классификационная голова. Qwen использует разность логитов yes и no с неизменной выходной проекцией.

| Вариант | nDCG@10 на top-20 | nDCG@10 на top-50 | Recall@10 на top-50 |
| --- | ---: | ---: | ---: |
| Готовый Qwen | 0,9621 | 0,9956 | 0,8715 |
| Qwen после 1 эпохи | 0,9268 | 0,9830 | 0,8544 |
| Qwen после 2 эпох | 0,9477 | 0,9871 | 0,8584 |
| BGE после 2 эпох с возвратами | 0,9781 | 1,0000 | 0,8737 |

На общем val 21 запрос. У всех вариантов Recall@50 равен 0,9814 и MRR@10 по пяти singleton-запросам равен 1,0000. Вторая эпоха выбрана по top-20 nDCG@10, как и у BGE. Qwen улучшился относительно готовой модели на двух top-50 запросах, ухудшился на двух, на 17 изменение nDCG@10 равно нулю. Train BCE по эпохам составила 0,1913 и 0,1001. Прогоны заняли 43,7 с обучения на общей H200 с паузой между батчами, пик зарезервированной памяти PyTorch 4,00 ГиБ. Времена для Qwen top-20 включают скоринг top-50.

Чекпоинт второго Qwen сохранён на H200 в `~/vk-mail-search-hackathon/runs/qwen-train-r1/best-finetuned.safetensors`. Все версии моделей, конфигурация, seed, SHA кода, разметки, кандидатов и чекпоинта есть в JSON. Прежний test повторно не запускался.
