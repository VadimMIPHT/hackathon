# Дообучение BGE на 40 новых запросах Jev

На 99 исходных запросах дообучение исключительно на `N-001`–`N-040` подняло nDCG@10 на 0,0298 по публичным меткам VK и на 0,0214 по меткам Jev относительно базового BGE. Прежний чекпойнт набрал больше по обеим версиям меток. Прежний чекпойнт обучался в том числе на исходных запросах, поэтому общий замер на 99 даёт для него ориентир с пересечением train и test.

## Разбиение и настройка

В таком переносе train — ровно 40 `N-*`, test — 99 исходных запросов VK. Пересечение по ID пустое. Для обучения взяты все 3 129 пар внутри нужного ящика и периода по расширенному парсеру дат. Из них 1 170 положительных и 1 959 отрицательных, 1 589 уникальных писем. Каждая метка проверена против полного файла `qrels_full.jsonl` из Jev. Обучение началось с опубликованных весов `BAAI/bge-reranker-v2-m3`. Параметры зафиксированы до запуска, включая две эпохи, последние два слоя и классификационную голову, AdamW, LR `2e-5`, batch 16, максимум 256 токенов, seed 42. BCE взвешена так, чтобы каждый запрос давал одинаковый суммарный вес. Исходные запросы и их метки не подавались в обучение и не использовались для выбора чекпойнта. Для теста использован заранее зафиксированный чекпойнт второй эпохи. Запуск один.

Все модели оцениваются на одних top‑50 E5. Прежний и расширенный фильтр дат дали одинаковые метрики для этих 99 запросов. MRR@10 посчитан по запросам с ровно одним релевантным письмом.

| Модель | nDCG@10 VK | Recall@10 VK | MRR@10 VK | nDCG@10 Jev | Recall@10 Jev | MRR@10 Jev |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| E5 | 0,8893 | 0,8489 | 0,9762 | 0,8804 | 0,8023 | 0,9737 |
| E5 → базовый BGE | 0,9424 | 0,8974 | 0,9484 | 0,9329 | 0,8428 | 0,9693 |
| E5 → BGE, обучение только на новых | 0,9723 | 0,9204 | 0,9841 | 0,9543 | 0,8604 | 0,9825 |
| E5 → прежний дообученный BGE | 0,9802 | 0,9245 | 1,0000 | 0,9651 | 0,8657 | 1,0000 |

Recall@50 одинаков у всех моделей, 0,9876 по VK и 0,9764 по Jev. BCE на train по эпохам 0,29205 и 0,09323.

## Пересечение с обучением

25 исходных запросов связаны с новыми через перефразы или пересекающиеся периоды. 31 исходный запрос имеет хотя бы одно релевантное письмо в обучающих парах. На оставшихся 68, чьи положительные письма целиком отсутствуют в обучающих парах, изменение nDCG@10 составило **0,9433 → 0,9731** по VK и **0,9389 → 0,9553** по Jev. Среди 99 запросов только три относятся к двум ящикам, полностью отсутствующим в обучении. На них все варианты BGE имеют nDCG@10 = 1,0000.
