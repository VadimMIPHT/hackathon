# Что сделано в `team-smartmail`

Проверена ревизия `afd7fd2db71edf87c9b41d2b490fc72efc3f882b`. Команда реализовала самостоятельный движок поиска писем. Он фильтрует по ящику, дате доступности и периоду из текста запроса, затем ранжирует через BM25. Разбор дат поддерживает интервалы и относительные выражения. В текстовой части есть русский Snowball-стемминг, префиксы и доменные синонимы. [Исходники команды](https://github.com/VadimMIPHT/hackathon/tree/afd7fd2db71edf87c9b41d2b490fc72efc3f882b).

Дополнительно реализованы квантованный E5-small через ONNX, гибрид BM25 + E5 через RRF, уточнение запроса RM3, дедупликация, стратификация и фильтр отправителя. Для синтетических запросов есть генерация перефразов и оценка по кластерам похожих писем. В замерах команды на исходном dev BM25 дал 0,963 nDCG@10, RRF — 0,947, BM25 с RM3 — 0,920. На расширенном наборе из 139 запросов команда измеряла предыдущую версию меток. Все 65 тестов из ветки прошли на данных ветки. [README команды](https://github.com/VadimMIPHT/hackathon/blob/afd7fd2db71edf87c9b41d2b490fc72efc3f882b/README.md).

## Сравнение на одинаковых запросах и метках

BM25 запущен с настройками `SearchEngine` по умолчанию. У каскадов взяты сохранённые выдачи E5 top‑50 с расширенным разбором дат. Границы распознанных периодов и число доступных писем совпали на всех 139 запросах. В таблице прежний BGE — чекпойнт, обучавшийся в том числе на части 99 исходных запросов. BGE из переноса обучался на 40 дополнительных запросах и оценивался на 99 исходных.

| Срез | Модель | nDCG@10 | Recall@10 | Recall@50 |
| --- | --- | ---: | ---: | ---: |
| Jev, все 139 | BM25 команды | 0,9748 | 0,7738 | 0,9789 |
| Jev, все 139 | E5 → прежний BGE | 0,9657 | 0,7627 | 0,9531 |
| Jev, дополнительные 40 | BM25 команды | 0,9485 | 0,4972 | 0,9484 |
| Jev, дополнительные 40 | E5 → прежний BGE | 0,9673 | 0,5079 | 0,8954 |
| Jev, 30 запросов из test-ящиков | BM25 команды | 1,0000 | 0,8538 | 0,9993 |
| Jev, 30 запросов из test-ящиков | E5 → прежний BGE | 0,9954 | 0,8496 | 0,9993 |
| VK, исходные 99 | BM25 команды | 0,9632 | 0,9031 | 0,9906 |
| VK, исходные 99 | E5 → BGE, обученный на новых | 0,9723 | 0,9204 | 0,9876 |
| VK, исходные 99 | E5 → прежний BGE | 0,9802 | 0,9245 | 0,9876 |

BM25 команды привёл в top‑50 больше релевантных писем на обеих разметках. Разница особенно заметна на 40 дополнительных запросах по Jev, где при этом каскад BGE лучше в первых десяти позициях. [Замер BM25](metrics.json) · [Все 139 по Jev](../jev-eval-r1/metrics.json) · [Перенос на 99 исходных](../jev-transfer-r1/comparison.json).

`team-smartmail` имеет отдельную историю и включает исходный корпус в Git. При переносе в общую ветку код движка можно вынести отдельным коммитом и оставить загрузку корпуса из локального архива. [Дерево ветки](https://github.com/VadimMIPHT/hackathon/tree/afd7fd2db71edf87c9b41d2b490fc72efc3f882b).

## Повторить замер

Понадобятся отдельная копия `team-smartmail` на указанной ревизии, распакованный `vk-jev-dataset` и исходный ZIP VK. Команда выполняется из корня этой ветки (`feature/e5-bge-search`).

```bash
PYTHONPATH="/path/to/team-smartmail:$PWD" python3 docs/benchmarks/team-smartmail/benchmark.py \
  --jev /path/to/vk-jev-dataset \
  --public /path/to/mipt_mail_search_participants.zip \
  --mailbox-split docs/benchmarks/mailbox-split.json \
  --team-commit afd7fd2db71edf87c9b41d2b490fc72efc3f882b \
  --metrics-commit e4007bee7def8d9e386d6c5eb2f6cbd7c475c68f \
  --output /tmp/team-smartmail-metrics.json
```
